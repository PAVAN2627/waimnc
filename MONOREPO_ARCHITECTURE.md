# Wai Municipal Council (वाई नगरपरिषद) — Monorepo Architecture & Security Blueprint

This repository is organized as a high-security, scalable **Turborepo monorepo** separating the public citizen portal, the internal administration portal, and the NestJS backend API.

## 2. Security Improvements

1. **Physical Code Isolation**:
   - `apps/web` contains **zero admin code or routes**. Public visitors inspecting browser JavaScript bundles can never view admin endpoints, internal models, or staff logic.
2. **Search Engine Protection**:
   - `apps/admin` has strict `noindex, nofollow, noarchive` tags so internal administrative login screens are never indexed by Google or Bing.
3. **Session & Token Hardening**:
   - JWT tokens are saved in `HttpOnly`, `SameSite=Strict`, `Secure` cookies, mitigating cross-site scripting (XSS) token theft.
4. **Cloudflare R2 Direct Uploads**:
   - Large tender PDFs and citizen grievance photos upload directly to Cloudflare R2 using short-lived (15-min) S3 presigned URLs generated by `apps/api`.
   - The backend server memory never handles heavy multi-megabyte payloads, and Cloudflare R2 offers **0 egress fees**.
5. **API Shielding**:
   - `@nestjs/throttler` protects against brute-force attacks and complaint form spam.
   - Helmet sets strict HTTP security headers (`Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`).
   - CORS strictly permits only your verified domains.

## 3. Subdomain DNS Setup

Configure the following DNS records in your Cloudflare dashboard:

| Subdomain | Record Type | Target / Value | Purpose |
| :--- | :--- | :--- | :--- |
| `waimunicipalcouncil.org` | CNAME / A | Vercel / Cloudflare Pages | Citizen Portal (`apps/web`) |
| `admin.waimunicipalcouncil.org` | CNAME / A | Vercel / Cloudflare Pages | Staff Admin Portal (`apps/admin`) |
| `api.waimunicipalcouncil.org` | CNAME / A | Cloud Run / Railway / VPS | NestJS API (`apps/api`) |
| `media.waimunicipalcouncil.org` | CNAME | Cloudflare R2 Bucket Domain | Zero-egress CDN delivery of tender PDFs & photos |

---

## 4. Cloudflare R2 Configuration

1. In Cloudflare Dashboard, go to **R2 Object Storage** > **Create Bucket** (name: `wmc-media`).
2. Under **Settings** > **Custom Domains**, connect `media.waimunicipalcouncil.org`.
3. Under **Manage R2 API Tokens**, create a token with **Object Read & Write** permissions.
4. Copy the credentials into `apps/api/.env`:
   ```env
   R2_ACCOUNT_ID="your_cloudflare_account_id"
   R2_ACCESS_KEY_ID="your_r2_access_key_id"
   R2_SECRET_ACCESS_KEY="your_r2_secret_access_key"
   R2_BUCKET_NAME="wmc-media"
   R2_PUBLIC_DOMAIN="https://media.waimunicipalcouncil.org"
   ```

## 5. PostgreSQL & Prisma Setup

1. Provide your PostgreSQL database connection in `apps/api/.env`:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/wai_municipal_council?schema=public"
   ```
2. Run database migrations:
   ```bash
   cd apps/api
   npx prisma migrate dev --name init
   ```
3. To view the visual database manager:
   ```bash
   npx prisma studio
   ```

## 6. Development Commands

From the monorepo root:

| Command | Action |
| :--- | :--- |
| `npm run dev:web` | Starts Citizen Portal on `http://localhost:5173` |
| `npm run dev:admin` | Starts Admin Portal on `http://localhost:5174` |
| `npm run dev:api` | Starts NestJS API on `http://localhost:3001/api` |
| `npm run build:web` | Compiles optimized production bundle for Citizen Portal |
| `npm run build:admin` | Compiles optimized production bundle for Admin Portal |
| `npm run build:all` | Builds all packages via Turborepo |
